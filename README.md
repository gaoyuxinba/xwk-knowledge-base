### 方式 A：双击启动（推荐）

1. 双击 **`启动服务.bat`** —— 启动网站（首次会自动装依赖，需联网约 1 分钟）
2. 浏览器打开 **http://localhost:3210**
3. 登录：账号 `gaoyuxi`　密码 `wt1201263`
4. **首次登录请立即修改密码**（系统会提示）

### 方式 B：命令行启动

```bat
cd /d 项目目录
npm install        :: 仅首次需要
npm start          :: 启动服务，默认端口 3210
```

改端口：`set PORT=8080 && npm start`

### 外网访问（给同事用）

1. 先用上面的方式启动服务，**保持那个窗口不要关**
2. 再双击 **`启动外网访问.bat`**
3. 窗口里会显示一个 `https://xxxx.loca.lt` 的公网地址，发给同事即可

注意事项：
- 这个窗口关掉，公网地址立刻失效；电脑关机或断网也会失效
- 每次重启地址可能变化（脚本已固定请求 `xwk-knowledge-base` 这个子域名，通常能保持）
- 同事首次打开会看到 localtunnel 的确认页，点 **Click to Continue** 就进入登录页
- 登录日志会记录对方的 IP、设备、浏览器、系统和时间

### 方式 C：部署到云端（永久在线，不用开电脑）

这是你要的「永久网站 + 线上修改」方案。分两步：代码放 GitHub，服务跑在免费云平台。

**第 1 步：推到 GitHub**

GitHub 从 2021 年起已停用「账号密码」做推送，必须用 Personal Access Token（PAT）：

1. 打开 https://github.com/settings/tokens
2. `Generate new token` → `Generate new token (classic)`
3. 勾选 **repo** 权限，有效期按需选（可选 No expiration）
4. 生成后复制 `ghp_` 开头的那串

然后运行（**不需要本机装 git**，脚本直接调 GitHub API 建仓推送）：

```bat
cd /d 项目目录
python deploy_github.py --token ghp_你的token --repo xwk-knowledge-base --private
```

脚本会自动：创建**私有**仓库 → 推送全部代码与数据 → 建立 `xwk-persist` 持久化分支。

> 仓库请保持 **Private**。这份知识库含账号密码哈希、行业风险判断与审批话术，属内部业务资料。
> 若设为 Public，服务端会自动跳过账号数据推送以防泄露（内置保护）。

**第 2 步：部署到免费云平台**（二选一）

| 平台 | 操作 |
|---|---|
| **Render** | https://render.com → `New +` → `Blueprint` → 选刚建的仓库。会自动读取 `render.yaml` |
| **Railway** | https://railway.app → `New Project` → `Deploy from GitHub repo` → 选仓库 |

两个平台都支持用 GitHub 账号一键登录。**部署后必须在环境变量里填这两个**（否则重启会丢数据）：

```
GITHUB_TOKEN = ghp_你的token
GITHUB_REPO  = 你的用户名/xwk-knowledge-base
```

完成后会得到一个永久地址（如 `https://xwk-knowledge-base.onrender.com`），关掉电脑也能访问。

**为什么需要 GITHUB_TOKEN？**

免费云平台的文件系统是**临时的**，重启就清空。本服务已内置持久化机制：
把账号、权限、人工编辑内容、日志打包成快照，推到仓库的 `xwk-persist` 分支；
重启时自动拉回。**所以你在线改的内容不会丢**，换设备登录也是同一份数据。

- 自动保存间隔 60 秒（有改动才写，无改动跳过）
- `xwk-persist` 是独立分支，**不会触发重新部署**，不会形成部署循环
- 可在「系统管理 → 系统自检与设置」页查看持久化状态、手动点「立即保存快照」
- 关机或重新部署前建议手动保存一次

免费层注意事项：闲置约 15 分钟后会休眠，首次访问需等 20-40 秒唤醒（之后正常）。

## 二、账号与权限

只有超级管理员能增删账号、分配权限。

| 角色 | 能做什么 |
|---|---|
| **超级管理员** | 全部权限：查看、编辑内容、增删账号、分配权限、看日志 |
| **编辑人员** | 查看 + 编辑行业/职业/城市风险内容（不能管账号） |
| **浏览人员** | 只能查看，任何修改都会被拒绝 |

三个权限开关是独立的，可以细粒度组合：
- **浏览查看权限** —— 能否查询看板和数据
- **页面编辑权限** —— 能否修改内容
- **账号管理权限** —— 仅超级管理员拥有

内置账号 `gaoyuxi` 受保护，**不可删除、不可停用、不可降级**，避免把系统锁死。可以改它的密码、姓名和备注。

在「系统管理 → 账号与权限」里可以：新增账号、重置密码、启用/停用、强制下线某个会话、设置首次登录必须改密。

## 四、数据来源与口径（重要）

全部数据来自 `小微行业知识库看板V3.xlsx`，各区块的取数路径**严格对齐看板公式**：

| 网页区块 | Excel 来源 | 说明 |
|---|---|---|
| 01 行业档案、03 前景利润 | `_idx` | 99 个细分行业 × 16 字段 |
| 02 经营模式 | `_m02` | 127 条模式 |
| 04 岗位核实 | `_m04` | 419 条 ＋ 补写 109 条 ＝ 528 条 |
| 05 城市风险分级 | `00_整合明细` 的 AF/AG 列 | 看板 05 区块公式 = 22表 N/O 列 = `INDEX('00_整合明细'!AF/AG, ...)`，所以取这里 |
| 城市清单 | `22_城市选择·搜索勾选` | 20 个城市，含序号与定位标签 |

### 三处按你的要求做的处理

1. **职业信息不用 `00_整合明细`**
   该表里 19 个行业的职业明细 6 个字段全是「—」占位符，没有实质内容。已改用 `_m04`，并按 `_m04` 的写法**补写了这 19 个行业共 109 条岗位明细**（每行业按职位名逐个拆开，7 个字段全部写实）：
   `CY05 卤味熟食`、`CY06 烧烤夜宵`、`SW05 快递驿站`、`SW06 图文快印`、`SW07 会展婚庆`、`ZZ08 五金加工`、`ZZ09 电子组装`、`ZZ10 纸箱彩盒`、`ZZ11 工艺品礼品`、`XX03 电商代运营`、`JY02 托育早教`、`YL02 宠物医院`、`YL03 体检中心`、`WL04 儿童乐园`、`WL05 桌游电竞`、`HB05 户用光伏`、`JT05 网约车出租车`、`NY05 苗木种植`、`FD02 装修装饰`

   补写内容属**行业经验判断**，不是官方统计，请在实际电核中结合当地情况使用，发现不合适的可直接在网页后台改。

2. **「面签时怎么问」统一改为「审核时怎么问」**
   字段名与全部内容均已替换，全库检索无「面签」残留。

3. **剔除数据不新的板块**
   `05_行业分层框架`、`07_城市画像对比`、`城市档案·太原/南京/重庆/青岛`、`城市行业差异交叉表` 全部不采用。城市风险只保留看板口径的那一套。

### 顺带修掉的一个 Excel 缺陷

Excel 的 `20_行业选择·搜索勾选` 表只有 **90** 个行业，比 `_idx` 的 99 个少 9 个（`JY02`、`YL02`、`YL03`、`WL04`、`WL05`、`HB05`、`JT05`、`NY05`、`FD02`），导致这 9 个行业在 Excel 看板里**根本搜不到**。网页版已补全到 99 个，全部可搜可查。

### 城市风险数据源的一个提醒

`_idx` 表里也存了一套城市层级与依据，但**看板公式并没有引用它**，两套数据存在 504 处层级差异、1751 处依据差异（例：`JZ01 郑州`，`_idx` 是「B-C级·中低风险」，`00_整合明细` 是「C级·中等风险」）。网页按看板公式的真实取值路径采用 `00_整合明细`，与你打开 Excel 看到的完全一致。如果哪天你确认 `_idx` 那套才是新版，告诉我，改一行配置就能切换。

## 五、查询逻辑与 Excel 完全一致

网页复刻了 Excel 三张选择表的公式，不是简单筛选：

- **行业定位**（复刻 20表 N6）：勾选优先 → 精确编号 → 精确三段式标签 → 唯一命中自动定位。**命中多条时不自动定位**，需勾选其一或细化关键词（与 Excel 行为一致）。
- **检索串**（复刻 20表 E 列）：编号 + 门类 + 细分行业 + 主体形态 + 证照 + 规模 + 订单来源 + 融资用途 + 前景 + 毛利 + 净利 + 旺季 + 淡季 + 资金缺口 + 风险 + 政策 + **职业标签串**，全部转小写后做子串匹配，所以能用岗位名（`安全员`）反查行业。
- **职业显示**（复刻 `_m21` F/G/I/K/L 列）：先限定本行业 → 再按关键词命中 → 若有任何勾选则只显示勾选项，否则显示全部命中 → 看板**最多渲染 10 条**。
- **城市显示**（复刻 22表 H/J/L/M 列）：命中判断含城市名、定位标签、三段式标签 → 若有勾选则只显示勾选项 → 看板**最多渲染 8 行**。
- **关键词归一化**：输入中的 `-` 会转成空格再匹配（复刻 `SUBSTITUTE(TRIM(x),"-"," ")`），所以粘贴 `JZ07-建筑业-防水防腐保温工程` 也能命中。

## 六、编辑与留痕

- 有编辑权限的账号，看板上每个字段右侧都有 `✎` 按钮，点开即可改。
- 修改写入**覆盖层**，Excel 提取的原始数据始终保留不动，随时可「还原为原始值」。
- 每次改动记录：操作人、时间、来源 IP、字段名、改动前的值、改动后的值。
- 「系统自检与设置」页可查看当前有多少字段被人工改过。

- 想重新从 Excel 提取数据：改 `build/extract.py` 里的源文件路径后重跑，会覆盖 `seed.json`。
